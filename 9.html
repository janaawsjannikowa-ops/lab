Вариант 1 - Выборка логотипа тремя разными способами

📌 Задание 1

Условие: У нас есть пример, в котором мы отбираем картинку из шапки сайта logo.jpg способом: $('img[src*=logo.jpg]').hide();

Задача: Сделать выборку этого же элемента двумя другими способами на ваше усмотрение.

🎯 Три способа выборки одного и того же элемента

Способ 1 (исходный)

$('img[src*="logo.jpg"]')

Поиск по частичному совпадению атрибута src

Способ 2 (по ID)

$('#main-logo')

Прямой доступ по уникальному идентификатору

Способ 3 (по родителю)

$('header .logo-area img')

Выборка по иерархии элементов

💡 Нажмите на любую кнопку способа, чтобы выполнить анимацию hide/show для логотипа

📊 Все три способа выбирают один и тот же элемент - логотип logo.jpg

📝 Дополнительная демонстрация

Пример из задания: изменение текста заголовка и анимация логотипа

$(document).ready(function(){
    var texH1 = $('#main_h1').text('текст измененный с помощью jquery');
    var myLogo = $('img[src*=logo.jpg]').hide();
    myLogo.hide(3000);
    myLogo.show(3000);
});

📚 Объяснение способов выборки

1. Исходный способ: $('img[src*="logo.jpg"]')

Использует селектор атрибута с подстрокой. Находит все изображения, у которых в атрибуте src содержится "logo.jpg".

2. Способ через ID: $('#main-logo')

Самый быстрый и эффективный способ. Использует уникальный идентификатор элемента. Рекомендуется для элементов, которые имеют ID.

3. Способ через иерархию: $('header .logo-area img')

Использует вложенность элементов. Находит все изображения внутри элемента с классом logo-area, который находится внутри header.

✅ Важно: Все три способа выбирают один и тот же DOM-элемент - наше изображение logo.jpg.

🎯 Вы можете убедиться в этом, выполнив выбор разными способами - результат будет одинаковым.
